2. Description of the Service

ZeroAgent is a free desktop application for macOS. It runs locally on your own computer, does not require an account to download or use, and lets you dispatch coding agent tasks to worker agents running on your own machine, shown as creatures on a canvas you can watch, drag, and talk to.

ZeroAgent drives coding agent command-line tools already installed on your computer, using your own model provider accounts and API keys. It is not a hosted service: your prompts, code, and model requests go directly from your machine to your chosen model provider under that provider's own terms, not through MVPLean.
